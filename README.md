# TorchDCM documentation

Published site: https://zhengzhong-you.github.io/torchdcm-docs/

This repository contains the generated HTML documentation for the TorchDCM development implementation.
The canonical documentation sources live in `documentation/` inside the TorchDCM software checkout.
API references are generated from that checkout; the examples and advanced interfaces may be newer than the released PyPI package.

Software repository: https://github.com/mbc96325/torchdcm

Built with Sphinx and Sphinx-Immaterial. Documentation and bundled examples follow the TorchDCM MIT license; theme assets retain their respective notices.
