    Inner problems, dynamic choice and paths¶

    An inner problem defines a state through a smooth residual equation. Supply the residual, an initial value, and all differentiable parameters to implicit_root. An external numerical solver may operate outside PyTorch; the residual remains differentiable and supplies the local derivatives.

    import torch
from torchdcm import implicit_root
theta = torch.tensor(4.0, dtype=torch.float64, requires_grad=True)
root = implicit_root(lambda r, t: r * r - t,
                     torch.tensor(1.0, dtype=torch.float64), theta)
slope, = torch.autograd.grad(root, theta, create_graph=True)
curvature, = torch.autograd.grad(slope, theta)

    The current implementation uses small dense systems on a smooth regular local branch, with first- and second-order derivatives. It checks the returned residual and state Jacobian. Derivative accuracy depends on solve tolerance and conditioning. It does not differentiate discrete solver choices or select among all equilibria.

    Representative uses¶

    • BellmanUtility: finite-state dynamic Logit with fixed discount and a fully available action set. The choice likelihood conditions on observed states; joint transition/initial-state likelihoods need explicit factors.

    • BLPDemand: demand-side share inversion and product-row moments. A custom share module must define valid log shares and a regularly invertible map.

    • RecursiveLogitUtility: small dense absorbing-walk partitions. Every nonterminal node must reach the destination and the transient weight matrix must have spectral radius below one. These are not arbitrary simple paths.

    For demand, see Demand-side BLP and GMM. Changing the share model can retain GMM; a new share map may need a different residual solver.

    API reference¶

    implicit_root(residual, initial, *parameters, solver=None, tolerance=1e-10, max_iter=50, return_info=False)¶

    Solve residual(state, *parameters) == 0 and differentiate its local root.

    initial is a nonempty scalar or vector float32/float64 tensor. The residual must return the same shape, dtype, and device. Pass differentiable inputs in parameters; the initial guess only selects a local branch and is detached. Residuals must be deterministic, smooth, and have a nonsingular state Jacobian at the solution. No global existence, uniqueness, or branch continuity is promised. Float64 and a tight residual tolerance are recommended for inference.

    The default damped Newton solver forms a dense Jacobian, intended for small states (quadratic storage and cubic solve cost). Alternatively, solver(residual, initial, *parameters) returns a state tensor of the same shape, dtype, and device. It receives detached copies under no_grad and may use NumPy or another external solver. Capture its solver-specific settings in the callback; max_iter controls only the default solver. The returned residual and Jacobian are checked independently; solver output alone never establishes convergence. return_info=True returns (state, ImplicitInfo). Callbacks must not mutate parameters, buffers, or other model state. no_grad and inference_mode return numerical solutions without a gradient graph. Pass inference tensors as explicit parameters, not captured closure variables, so the local derivative checks can use ordinary copies.

    First and second derivatives come from two differentiable Newton corrections at the detached solution, retaining the full Jacobian dependence. At an exact regular root Newton’s state derivative is zero: parameter perturbation error changes from O(h) to O(h**2) then O(h**4), giving the implicit first and second derivatives. At numerical roots their accuracy depends on solve tolerance and conditioning. No solver history is retained. Derivatives beyond order two, torch.func transforms, nonsmooth/active-set changes, and discrete/MIP solvers are outside this contract. Use ordinary torch.autograd for derivatives.

    implicit_fixed_point(mapping, initial, *parameters, solver=None, tolerance=1e-10, max_iter=2000, return_info=False)¶

    Solve x = mapping(x, parameters), reusing root validation and derivatives.

    Default iteration requires a convergent fixed-point map. A custom solver uses the same residual-based signature as implicit_root. Inputs/branch regularity and the small dense first/second derivative contract are unchanged.

    implicit_minimize(objective, initial, *parameters, solver=None, tolerance=1e-10, max_iter=50, return_info=False)¶

    Differentiate a smooth unconstrained strict local minimum.

    objective(state, *parameters) must return a scalar tensor. Solves its stationarity equations through implicit_root() and checks a positive definite state Hessian. These numerical checks do not certify a local or global optimum; use a strongly convex objective for uniqueness. The residual smoothness contract requires corresponding higher objective derivatives. An external solver receives the stationarity residual, exactly as in implicit_root; wrap an objective-based solver in a callback if needed.

    class BellmanUtility(payoff, transition, discount, *, solver=None, tolerance=1e-10, max_iter=2000)¶

    Payoff module returns state/action utility; observed data supplies x_obs[‘state’].

    Use ModuleChoiceModel.from_utility. Each observed choice set must contain all action IDs 0..A-1. Observed states are conditioned on; transition likelihood and initial-state likelihood are not estimated by this adapter.

    class BLPData(x: torch.Tensor, random_x: torch.Tensor, shares: torch.Tensor, instruments: torch.Tensor, market: torch.Tensor, draws: torch.Tensor, draw_weights: torch.Tensor)¶
    class BLPDemand(beta, log_sigma=None, *, share_model=None, solver=None, tolerance=1e-10, max_iter=2000)¶

    Return product-level instrument times demand-error moments.

    x includes all linear regressors (including any constant). random_x uses diagonal positive scales exp(log_sigma) by default; share_model can replace this entire log-share calculation. It must support the inversion map and return one log inside share per product. Supplied integration nodes remain fixed. This is demand-only GMM, not price-equilibrium or supply estimation.

    mean_utilities(data)¶
    predict(data, xi=None)¶

    Shares at supplied structural errors; xi=None explicitly means zero errors.

    Hold xi fixed for a counterfactual. To reproduce observed shares, obtain fitted xi as mean_utilities(data)-data.x@beta; that is an inversion check, not out-of-sample predictive validation.

    class RecursiveLogitUtility(payoff, source, target, n_nodes, destination, *, solver=None)¶

    Supply edge utilities; observe outgoing-edge choices grouped by route.

    Data x_obs[‘state’] records the node; alternative IDs are global edge IDs. Availability is encoded by listing all outgoing edges. Independent routes are panel individuals, so route contributions/scores remain available.
