    Built-in model reference¶

    Constructor signatures below come from the development checkout. Choose the statistical law first, then define its utility or component specification. MNL, Mixed Logit and module entry points are described in Choice models and custom utilities.

    class Nest(alternatives, init=0.8, fixed=False, name=None)¶

    A disjoint nested-logit nest.

    lambda is the dissimilarity parameter. Values close to one recover MNL within the nest structure, while smaller values imply stronger correlation.

    class NestedLogit(spec, nests, *, dtype=torch.float64, device='cpu', max_iter=200, tolerance_grad=1e-07, line_search_fn='strong_wolfe', lambda_min=0.0001)¶

    Nested logit model with disjoint nests and linear utilities.

    class CrossNest(allocations, init=0.8, fixed=False, name=None)¶

    A cross-nested logit nest with fixed allocation weights.

    Cross-nested logit with fixed allocation weights and estimated lambdas.

    fit(data, *, cov_type='classic', max_iter=None)¶
    predict_proba(data, params, compiled=None)¶
    class RandomCoefficient(name, sigma_init=0.1, sigma_name=None, distribution='normal', fixed=False)¶

    Random coefficient specification.

    The location parameter is the corresponding Beta in the utility specification. For lognormal variants, that parameter is on the latent normal scale. The standard deviation is represented by sigma_name and constrained to be non-negative during estimation unless it is fixed.

    class WTPCoefficient(name, variable, init=0.0, sigma_init=0.1, sigma_name=None, distribution='normal', fixed=False, sigma_fixed=False)¶

    WTP-space coefficient attached to an attribute variable.

    class WTPMixedLogit(spec, *, cost, cost_variable, wtp_coefficients, n_draws=128, draws=None, seed=12345, antithetic=True, panel=True, correlated=False, dtype=torch.float64, device='cpu', max_iter=200, tolerance_grad=1e-07, line_search_fn='strong_wolfe', sigma_min=0.0)¶

    Mixed logit parameterized in willingness-to-pay space.

    Utilities are evaluated as:

    V = deterministic_terms + B_COST * cost + B_COST * sum(WTP_k * x_k).

    class LatentClassLogit(class_specs, *, class_membership=None, dtype=torch.float64, device='cpu', max_iter=200, tolerance_grad=1e-07, line_search_fn='strong_wolfe')¶

    Latent class logit with class-specific MNL utilities.

    The first class is the reference class with membership logit fixed to zero. Each additional class can use a linear membership expression such as Beta("CLASS_2") + Beta("CLASS_2_GA") * "ga".

    class CovariateScale(log_scale=None, value=None)¶

    Alternative scale defined by scale = exp(log_scale).

    Use value for a fixed scale, or log_scale for a linear expression whose exponent gives the row-specific scale.

    class HybridChoiceModel(spec, *, latent_variables, choice_effects=None, indicators=None, n_draws=128, draws=None, seed=12345, antithetic=True, panel=True, dtype=torch.float64, device='cpu', max_iter=200, tolerance_grad=1e-07, line_search_fn='strong_wolfe', sigma_min=1e-09)¶

    Hybrid choice model with MNL choice kernel and Gaussian measurement model.

    The implemented likelihood is the joint likelihood of the observed choice and continuous indicators, integrated over normally distributed latent variables using Monte Carlo draws.
