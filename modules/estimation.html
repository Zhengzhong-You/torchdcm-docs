    Estimation, inference and queries¶

    Select the statistical target before selecting the fitting interface.

    Target

    Input

    Result

    Likelihood

    One completed observed log contribution per independent unit

    Estimates, appropriate covariance and explicit queries

    Composite likelihood

    Dependent marginal pieces grouped within sampling units

    Sandwich inference; no ordinary likelihood information criteria

    GMM

    Moment rows and an independent-unit or cluster mapping

    Criterion, weights, estimates and moment-based covariance

    Posterior

    Likelihood, prior and required transform Jacobian

    Draws, posterior quantiles and sampling diagnostics

    Moment inequalities

    Bounded independent moment rows and a prespecified finite grid

    Separate sample-feasibility and confidence masks

    Likelihood and moments¶

    LikelihoodModel accepts a module, or from_callable with a named parameter mapping. Return log contributions, a scoped factor, or a completed likelihood objective. Use measure="density" or measure="mixed" when appropriate; continuous log densities need not be nonpositive.

    Use objective_kind="composite" for a composite target. Keep dependent pieces in the same record or specify appropriate covariance clusters.

    GMMModel accepts row-level moment vectors and supports one- or two-step estimation. The weight matrix is fixed within each step. A cluster mapping changes covariance construction, not the definition of the moment mean.

    Fitted queries¶

    predict calls an explicit module prediction method. predict_proba requires a discrete-probability method. Exponentiating a fitted density is not a choice forecast. export_module returns the fitted mechanism for a named query. Likelihood results expose delta_method for suitable smooth scalar transforms. Use economic definitions appropriate to the model for willingness to pay or elasticities.

    API reference¶

    class LikelihoodModel(kernel, *, measure='mass', objective_kind='likelihood', **kwargs)¶

    Module.forward(data) returns observed contributions, not unchosen alternatives.

    Return a length-N tensor, a scoped LogFactor, or a finalized objective. measure declares mass/density/mixed; density values may exceed one. A module’s optional predict(data, …) defines its own prediction object.

    sample_posterior(log_density, initial, *, draws=1000, warmup=500, step_size=0.1, leapfrog_steps=8, seed=0)¶

    Metropolis-corrected fixed-step HMC, identity mass, explicit user tuning.

    log_density(theta) includes likelihood, prior, and any transform Jacobian. Initial states [chains,P] must be in unconstrained coordinates. Warmup is discarded, not adaptation; inspect diagnostics before using posterior draws. Small finite-dimensional targets only; no NUTS, automatic mass adaptation, marginal likelihood, or guarantee that separate modes were explored.

    posterior_diagnostics(samples)¶

    Rank-normalized/folded split R-hat, bulk and 5%/95% tail ESS.

    moment_region(grid, moments, lower, upper, *, alpha=0.05)¶

    moments(theta)->[N,M], with independent observation rows and E[m]<=0.

    Known deterministic bounds lower[M]<=m<=upper[M], valid at every grid point. A Hoeffding union bound covers all true grid points simultaneously with probability >=1-alpha. Grid and bounds must be chosen independently of the sample. No interpolation coverage, sharpness claim, or adaptive-grid validity.
