    Choice models and custom utilities¶

    For a supported linear utility, define named coefficients with Beta and alternative-specific expressions with UtilitySpec. Select the corresponding built-in model and reuse its estimation and result methods.

    Model family

    Public classes

    Multinomial and nested

    MultinomialLogit, NestedLogit, CrossNestedLogit

    Random coefficients

    MixedLogit, WTPMixedLogit, ErrorComponentsLogit

    Heterogeneity and scales

    LatentClassLogit, ScaledMultinomialLogit, CovariateScaledMultinomialLogit

    Ordered and latent-variable responses

    OrderedLogit, OrderedProbit, HybridChoiceModel

    Existing neural components¶

    ModuleChoiceModel.from_utility(module) accepts a registered nn.Module that returns one utility per long row. A callable can instead use a named parameter mapping. The wrapper adds the Logit law and applicable estimation. A different conditional probability law can return normalized log probabilities to ModuleChoiceModel directly.

    Constants and simulation draws should be fixed buffers. Forward evaluations must be deterministic and avoid changing state. Shared parameters retain their identity; frozen parameters remain fixed. Results use registered parameter coordinates. A large neural model can use cov_type="none" when dense Hessian inference is inappropriate.

    # utility is a registered module; data is a prepared ChoiceDataset.
model = ModuleChoiceModel.from_utility(utility)
result = model.fit(data, cov_type="none")
fitted_utility = model.export_utility(result.params)

    For rankings or joint probability/density contributions, use Estimation, inference and queries and Joint responses and latent integration rather than fabricating a chosen row.

    class ModuleChoiceModel(kernel, *, panel=False, dtype=torch.float64, device='cpu', max_iter=200, tolerance_grad=1e-07, line_search_fn='strong_wolfe', hessian_batch_size=16)¶

    Fit a probability kernel without implementing an estimator.

    kernel.forward(data) returns unweighted conditional log probabilities on long rows, with an optional final equal-weight draw axis. Draws must be fixed buffers, shared over occasions when panel=True. Likelihood sums repeated occasions before integrating; prediction returns population marginal probabilities, not probabilities conditional on past choices.

    Alternatively, return a composition.LikelihoodObjective. Its explicit unit determines likelihood units and clustering, and its retained choice branch supplies population prediction. Joint models may supply an explicit null likelihood; otherwise null-model statistics are unavailable.

    Trainable nn.Parameters (including native torch parametrizations) are flattened automatically. Results and covariance use their registered, unconstrained coordinates. Frozen parameters and buffers are preserved. Kernels must be deterministic and must not mutate parameters or buffers.

    classmethod from_callable(function, parameters, **kwargs)¶

    Register named parameters for a function(parameters, data) hook.

    The function returns either conditional log probabilities or a composed LikelihoodObjective. All trainable tensors must come from parameters; use the nn.Module interface for trainable nested modules or buffers.

    classmethod from_utility(utility, parameters=None, **kwargs)¶

    Fit a module returning long-row utilities using the Logit choice law.

    A function taking (parameters, data) is also accepted with a named parameter mapping. Module mode and frozen/shared parameters are preserved; use deterministic eval mode for dropout or running-statistic modules.
