    Data and observation units¶

    Use ChoiceDataset for one chosen alternative per choice situation. It supports long-row data and conversion from wide data, availability masks, and individual identifiers. OrderedChoiceDataset serves ordered responses.

    Use ObservationBatch for rankings, complete sequences, continuous outcomes, or another explicitly defined record. Its payload is a dictionary of tensors; n_obs describes records, not alternatives, periods, or simulation draws.

    from torchdcm import ObservationBatch
data = ObservationBatch({"x": x, "ranking": ranking}, len(x), "ranking")

    Here x has shape [N, J, F] and ranking has shape [N, K]. Both are prepared inputs. For a sequence model, one complete independent sequence can be one record. Supported parent aggregation uses an explicit mapping.

    Grouping and weights¶

    • PanelStructure aggregates conditional contributions within individuals.

    • The general likelihood interface uses integer replication frequencies after latent integration. These are not survey or integration weights.

    • Cluster labels describe dependence between complete likelihood units.

    • Preserve mask and index dtypes when moving floating-point inputs to a device.

    API reference¶

    class ChoiceDataset(obs_ptr, alt_id, chosen_row, x_alt, weights, availability, obs_ids, alt_names, obs_to_ind=None, individual_ids=None, x_obs=<factory>)¶

    Ragged long-format choice data.

    Each observation occupies the segment obs_ptr[n]:obs_ptr[n + 1] in the row-level tensors. chosen_row[n] is the global row index of the selected alternative for that observation.

    class ObservationBatch(payload, n_obs, unit_label='record', weights=None, obs_to_ind=None, individual_ids=None)¶

    A payload and declared records. person is the optional legacy parent level.

    unit_label describes what one base record means (ranking, allocation, sequence, market, …). Frequency weights are not survey/importance weights. Tensor fields may have arbitrary event dimensions after their record axes.

    sum_by_unit(values)¶

    Sum observation-level values by individual.

    values must have observations on axis 0. Remaining dimensions are preserved, so this works for (n_obs,) and (n_obs, n_draws).

    logmeanexp_by_unit(obs_log_values, dim=1)¶

    Aggregate observation log-probabilities into panel log likelihoods.

    The common mixed-logit case passes an (n_obs, n_draws) tensor. The method first sums repeated observations for each individual and then averages over draws in log space.
