    Histories and hidden states¶

    A deterministic recurrent history and a hidden Markov state describe different mechanisms. HistoryUtility computes a pre-choice state through an explicit recurrence. markov_eliminate sums over unobserved state sequences from emission and transition log factors.

    Hidden Markov models¶

    Emission factors use trailing [time, state] dimensions. Transition factors broadcast to [..., time-1, previous_state, next_state]. Leading dimensions can index individuals or integration nodes. Declare sequence lengths so padding contributes no evidence.

    Filtered beliefs use available history. Smoothed beliefs can use future observations. A forecast uses the final filtered beliefs and supplied next-period transitions and optional emissions; it must not read the next response label.

    Ranked hidden Markov model gives a complete ranking-emission example. To add permanent preferences, run state elimination at each preference node and integrate outside the complete sequence.

    API reference¶

    class HistoryState(before, final, person_ids, last_order)¶

    States aligned to input observations and declared individual identifiers.

    class HistoryUtility(cell, inputs, head, *, order, initial_state)¶

    An eager tensor-state scan with chronological, person-specific resets.

    inputs(data) returns a tensor with observations on axis zero. Each row must use only that occasion’s transition features; its observed choice may be included because the cell updates after that occasion is predicted. cell(inputs_batch, state_batch) returns a tensor of the same state shape; an nn.GRUCell or a custom pure tensor-state module can be used directly. head(data, states_before) returns one utility per long row. It must use current exogenous features and the supplied state, not choice labels or other occasions. All three callbacks must be registered nn.Modules.

    The fixed initial-state tensor is reset independently for every person. Pass nn.Parameter to estimate a shared initial state. Initial state excludes the batch dimension. Only tensor states are supported (not LSTM tuples). Modules must not mutate their inputs, state, parameters, or buffers.

    order names a fixed, finite numeric x_obs column. Times must be unique within each person; observations may arrive shuffled and have ragged lengths. Likelihood is teacher-forced and conditional on observed past choices. predict_next uses only observed history, one later query per known person. Query datasets still contain dummy chosen_row entries to satisfy the existing ChoiceDataset format; this method does not read them or call inputs(queries).

    markov_eliminate(log_emissions, initial_logits, transition_logits, *, lengths=None, smooth=False)¶

    Marginalize hidden states, preserving one likelihood per independent sequence.

    Emissions […, time, state] may be probability masses or densities. Transitions broadcast to […, time-1, previous_state, next_state]. Initial logits broadcast to […, state]. Missing/padded times consume no evidence. Permanent random-effect axes should be integrated after this operation.

    class MarkovResult(log_likelihood: torch.Tensor, filtered: torch.Tensor, smoothed: torch.Tensor | None, final: torch.Tensor)¶
    forecast(transition_logits, emission_probabilities=None)¶

    Next hidden-state belief, optionally mapped to next outcome probabilities.

    No future observed outcome is consumed. Emission rows are state-conditional.
